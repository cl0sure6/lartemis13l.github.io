Peer-reviewed papers, preprints, and manuscripts in progress.

PDFs are hosted on this site: drop a file in `static/preprints/` and it becomes
available at `/preprints/<filename>.pdf`, then link it from the entry. To add a
publication, copy the example file in `content/publications/` to a new `.md` file.
